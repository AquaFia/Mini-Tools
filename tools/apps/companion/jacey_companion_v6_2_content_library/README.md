# Jacey Companion v6.2 — Content Library

Serve this folder through a local or web server. Open `jacey_companion_framework_v6_2_content_library.html`.

Built-in files are listed in:
- `episodes/episode_list.json`
- `message_banks/message_bank_list.json`

Built-in content can be enabled or disabled but not deleted. Manually imported episodes and message banks can be enabled, disabled, replaced by importing another file with the same displayed title, or deleted without reloading.
