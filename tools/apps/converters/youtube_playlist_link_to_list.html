YouTube Playlist → Copyable List

Paste a YouTube playlist link, fetch every video, then copy the whole list at once.

One-time setup: create a Google Cloud project, enable YouTube Data API v3, then create an API key under APIs & Services → Credentials. Paste that key above. The key stays in this page and is only sent to Google's YouTube API when you press Fetch Playlist.

For public or unlisted playlists accessible to the API, no YouTube login is required. Private playlists require OAuth and are outside the scope of this simple version.
